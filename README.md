
## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Ali-Alshaikh/Data-Sprint-Project.git
cd Data-Sprint-Project
```

### 2. Run the Notebooks in Order

Make sure your environment has all the necessary dependencies (e.g., Jupyter, pandas, scikit-learn, etc.)

`1. extract_olist_estimate.ipynb`
- Extracts the estimated delivery days from the Olist dataset.
`2. Olist-ML.ipynb`
- Prepares and trains both machine learning and deep learning models.
`3. GUI.ipynb`
- Provides a graphical interface to interact with the ML/DL models.
`4. which_estimation_is_better.ipynb`
- Compares the models and recommends the best one for the Olist company.
